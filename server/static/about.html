INDEPENDENT DEVELOPMENT TOOL

Explore Jade firmware, without a hardware device.

jade.church runs Blockstream Jade firmware as libjade, a native library, and lets you interact with the emulated device in your browser. It is a workspace for development, debugging, and testing firmware behaviour.

THE JADE.CHURCH WEB INTERFACE
INSIDE THE TOOL

A hands-on firmware workspace

Use the browser interface to explore the same emulated device across interactive sessions and repeatable test flows.

▣

Emulated device

View the firmware screen, press its buttons, change firmware builds, and capture screenshots. You can also feed QR images to the firmware’s scanner.

⌁

Test and inspect

Run scripted flows, inspect firmware activity, and use the RPC console to send messages and examine raw replies.

◉

Connect your tools

A TCP port speaks Jade’s CBOR-RPC protocol, allowing tools such as jadepy and test suites to drive the emulated device.

⚠
USE TEST DATA ONLY

Never use real funds or secret material

This is a development simulator, not a secure wallet. Anything entered into an instance—including a recovery phrase or mnemonic—must be considered public and compromised. Never enter a real seed or secret here.

⌘

Run it yourself

The project is open source. Download the code, follow the setup instructions, and run an instance on a machine you control.
