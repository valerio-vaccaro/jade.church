This is a test pinserver. It uses the key pair committed in the Jade repository, so its private key is public and the PINs it guards protect nothing. Use it with test wallets only, never with real funds.

Configure a Jade

On the Jade

  1. Turn it on and tap the front button while the logo is showing, to open the startup menu.
  2. Choose Blind Oracle, then Scan Oracle QR, and scan this code.
  3. Check the URL and public key on screen and confirm.

A Jade that already has a wallet refuses a new public key (“Cannot update initialized unit”): factory reset it first. The Jade does not connect to the pinserver itself: the companion app does, so the URL must be reachable from the phone or computer running it.
